## 变更

- 首页冷启动或从设置返回时，重新隐藏系统状态栏；兼容 MIUI 启动时重新挂载状态栏的行为。
- 设置、应用抽屉、本地音乐、收听记录页统一隐藏状态栏。
- 顶部下滑仍可临时唤出状态栏，随后自动隐藏；媒体源、通知授权、清空记录弹窗不会闪现状态栏。

## 已知限制

- 外部 App 收听记录仅在本应用进程存活且通知使用权开启时可用。
- 蓝牙硬件按键需在真实耳机/车机环境实测。
- 安全锁屏设备重启后需先解锁，Android 才会启动默认 HOME。
