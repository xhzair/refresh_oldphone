# Refresh Old Phone 1.0.0

把闲置 Android 手机变成 Walkman 风格、只属于音乐的媒体桌面。

- 签名证书 SHA-256：`7488F5369A8A74A3C35543ED96D087553BECC2351E1C7AFF6A9B5A3319CDFE53`

## 亮点

- 默认 HOME：大时钟、日期、网络/电量，可随时恢复系统桌面。
- 媒体源切换：网易云音乐、QQ 音乐、小宇宙等；官方源自动发现，可添加其他媒体 App。
- 跨应用播放卡片：曲名、作者、封面、进度与当前会话支持的控制。
- 本地音乐：全部歌曲、播放/暂停/切歌、进度、MediaStyle 通知、后台播放、蓝牙 A2DP 输出。
- 单源互斥：本地与外部媒体源自动暂停，避免同时播放。
- 所有应用抽屉、隐藏状态栏、屏幕常亮、横屏封面模式。
- 月度收听记录（仅外部 App）：时长、活跃天数、Top 歌曲/歌手/专辑、来源占比、24 小时分布；数据仅存本机，可清空。

## 修复

- 从本地音乐/设置/应用抽屉/收听记录等子页面按 HOME 现在会正确回到媒体桌面。
- 本地音乐不再写入收听记录；旧版本留下的本机会话也不会显示。
- 收听记录按来源关闭会话，避免外部观察与本地服务互相误关；暂停快照不会关闭另一来源的活跃会话。
- 收听记录写入失败会记录日志并回调失败；关闭数据库前排空排队写入。
- Android 15/16 edge-to-edge 下首页左侧 24dp 内边距丢失（时钟/日期贴边）已修复。

## 已知限制

- 外部 App 收听记录仅在本应用进程存活且通知使用权开启时可用；页面固定显示覆盖说明。
- 本地音乐只有“全部歌曲”，无专辑/歌手/文件夹/搜索/歌单/随机循环/歌词。
- 蓝牙音乐依赖系统 A2DP，具体耳机/车机按键行为需硬件实测。
- 安全锁屏设备重启后需先解锁，Android 才会启动默认 HOME。
- 未做年度回顾、分享图导出、云同步。
