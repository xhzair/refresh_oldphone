# 隐私说明（0.1）

媒体桌面（RefreshOldPhone，包名 `io.github.xhzair.refresholdphone`）是一个纯本地应用。0.1 版本没有服务器、没有账号系统、没有广告、没有遥测，也不会上传任何使用数据。

## 应用会处理什么

| 数据 | 来源 | 用途 | 是否离开设备 |
| --- | --- | --- | --- |
| 时间、日期 | 系统时钟 | 显示首页时钟/日期 | 否 |
| 电量、充电状态 | 系统 `ACTION_BATTERY_CHANGED` 广播 | 显示设备状态 | 否 |
| 网络类型（Wi‑Fi/移动网络/以太网/离线） | `ConnectivityManager` | 显示设备状态，不做 SSID/位置识别 | 否 |
| 已安装且可启动的媒体 App 包名与图标 | `PackageManager` | 展示媒体入口、附加应用选择 | 否 |
| 当前播放的曲名、作者、封面、进度、播放状态、可用控制 | 系统 `MediaSessionManager`（仅在用户授予通知使用权后） | 显示首页“正在播放”卡片并发送受支持的控制命令 | 否 |
| 本地音频的标题、歌手、专辑、时长、封面 | 系统 `MediaStore`（仅在用户授予音频读取权限并打开“本地音乐”后） | 显示本地音乐库、播放当前歌曲与通知 | 否 |
| 外部 App 的收听记录（来源包名、曲名/歌手/专辑、开始时间、收听时长） | MediaSession（仅通知使用权开启且本应用进程存活时观察） | 生成本机月度收听统计 | 否 |
| 通知使用权是否开启 | `NotificationManagerCompat` | 决定显示播放卡片还是授权提示 | 否 |

## 应用不会做什么

- 不读取、不解析、不记录、不上传通知正文或通知历史。
- 不收集位置、通讯录、短信、通话、相机、麦克风。
- 不扫描、上传或修改用户的非音频文件；本地音乐只读取系统媒体库索引到的音频元数据与音频内容。
- 不保存第三方 App 的账号、Cookie 或令牌；收听记录只在本机保存外部 App 的播放元数据与时长，用于月度统计，不上传。
- 本地音乐不计入收听记录；外部 App 只记录本应用进程存活且获得通知使用权时可观察到的 MediaSession，进程被杀/未授权期间会缺失。
- 不保存、不缓存播放封面到磁盘（封面仅在内存中按显示尺寸缩放后供界面使用，包括封面卡片与全屏背景）。
- 不逆向第三方 App 接口，不代理第三方 App 的网络流量。
- 不请求 root、设备管理、无障碍服务、VPN 或锁屏任务权限。

## 本地保存的配置

应用只使用本机 SharedPreferences（文件名 `media_shell`）保存以下键：

| 键 | 内容 |
| --- | --- |
| `orientation` | 方向偏好：`AUTO` / `PORTRAIT` / `LANDSCAPE` |
| `keep_screen_on` | 是否保持屏幕常亮 |
| `hide_status_bar` | 是否隐藏系统状态栏 |
| `selected_apps` | 用户主动添加的附加媒体 App 包名集合 |
| `last_launched_media_package` | 最近一次成功启动的媒体 App 包名（用于横屏空状态提示） |
| `last_media_source` | 最近一次选择的媒体源（`app:<包名>` / `local` / `bluetooth`） |

不包含任何播放内容、账号或通知数据。设置页“清除本地配置”会删除以上全部键，且不会影响任何第三方 App 的数据。

此外，月度收听记录保存在本机 SQLite 数据库 `listening_stats.db`（仅外部 App 的播放元数据与收听时长，本地音乐不计入）；可在“设置 → 收听记录 → 清空收听记录”删除，卸载应用也会删除。该数据库不上传；是否被 Android 系统备份由设备备份设置控制。

## 系统权限/能力说明

- `ACCESS_NETWORK_STATE`：仅用于区分 Wi‑Fi、移动网络、以太网、离线。
- `READ_MEDIA_AUDIO`（Android 13+）/ `READ_EXTERNAL_STORAGE`（Android 12 及以下）：仅在用户打开“本地音乐”并授予后读取系统媒体库中的音频元数据与音频内容；不上传、不修改文件。
- `FOREGROUND_SERVICE` / `FOREGROUND_SERVICE_MEDIA_PLAYBACK`：本地音乐播放时保持前台服务与媒体通知；通知可关闭，拒绝通知权限不阻塞播放。
- Notification Listener（通知使用权）：系统会将其描述为“可访问通知”，但本应用只在其授权范围内调用 `MediaSessionManager.getActiveSessions()` 读取 MediaSession 暴露的播放元数据，并向当前会话发送用户点击的播放控制命令；不读取通知内容。用户可随时在系统“通知使用权”页面关闭，关闭后应用降级为纯启动器。
- 蓝牙输出使用系统 A2DP 音频路由与 MediaSession/AVRCP，不申请蓝牙配对/连接权限，也不读取蓝牙设备内容。

## 数据删除

- 设置页“清除本地配置”：清除上述 SharedPreferences。
- 卸载应用：删除本应用全部本地数据。

## 第三方应用

本项目通过 Android 公开 Intent 启动用户已安装的官方 App，播放、登录、会员与版权由第三方 App 负责。请同时参考对应平台的隐私政策。
