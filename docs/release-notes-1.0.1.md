# Refresh Old Phone 1.0.1

1.0.0 的修复版本：保持媒体弹窗沉浸式，避免系统状态栏闪现。

- `refresh-oldphone-1.0.1.apk`（约 3.6 MB）
- 最低 Android 6.0（API 23），`versionCode 3`，`versionName 1.0.1`

- 签名证书 SHA-256：`7488F5369A8A74A3C35543ED96D087553BECC2351E1C7AFF6A9B5A3319CDFE53`

## 变更

- 媒体源、通知授权、清空收听记录等弹窗显示时隐藏系统状态栏，和桌面保持一致的沉浸式外观。
- 其余功能与 1.0.0 相同：媒体桌面、本地音乐、外部 App 卡片、单源互斥、应用抽屉、仅外部的月度收听记录。

## 已知限制

- 外部 App 收听记录仅在本应用进程存活且通知使用权开启时可用。
- 蓝牙硬件按键需在真实耳机/车机环境实测；本机无已连接蓝牙音频设备。
- 安全锁屏设备重启后需先解锁，Android 才会启动默认 HOME。
